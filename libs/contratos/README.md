# Contratos

Espacio reservado para interfaces y tipos que definan comunicaciones compartidas
entre aplicaciones y librerías.

Actualmente no publica tipos, DTO, endpoints ni eventos nuevos. Los contratos
que utiliza el frontend del gimnasio siguen definidos por `apps/gym-api/src/`.

La siguiente etapa determinará qué contratos deben compartirse, sus consumidores
y cómo mantener su compatibilidad. Los detalles internos de un negocio no se
convertirán automáticamente en contratos comunes.
